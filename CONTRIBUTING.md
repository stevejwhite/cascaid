# Contributing

Thank you for your interest in CascAid.

Issues and suggestions are welcome. Pull requests can be accepted only from contributors
who have signed a contributor licence agreement with the copyright holder, so that the
project can continue to be offered under other licences as well as the AGPL. Please open
an issue to ask before starting substantial work.

Contributed cases must be original fiction: no real patient data, and no RCPsych station
scripts, question banks or eLearning content. Read AGENTS.md for the project's rules.
